# Style a FigureIt scene

Use only style properties and object data included in the supplied scene. Preserve the figure's meaning and text. Prefer a restrained palette, consistent stroke widths, clear foreground/background contrast, and a small hierarchy of emphasis.

Keep text readable, avoid encoding meaning by color alone, and preserve existing transparent or monochrome intent unless explicitly asked to change it. Do not introduce fonts, packages, assets, effects, or TikZ options outside FigureIt's supported operation schema.

Return the smallest atomic proposal. State the visual rationale briefly. If no safe improvement is supported, return no operations.
